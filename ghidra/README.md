# Ghidra Project Template

> 说明：此目录包含用于在本地（隔离环境）创建 Ghidra 项目并进行静态分析的模板与脚本。

重要安全与合规声明
- ⚠️ 请勿将任何可执行样本或可复现的 payload 上传到本仓库的公开分支。所有分析必须在隔离的虚拟机或沙箱中进行。上传到仓库的仅限分析文档、导出结果和无害脚本。
- 在开始分析前，请确保你拥有合法权限并遵守所在机构与法律法规。

目录说明
- ANALYSIS_CHECKLIST.md — 分析流程与检查清单（静态优先、动态慎用）。
- HEADLESS_ANALYSIS.md — headless（无 GUI）批处理分析模板命令与注意事项（仅示例）。
- ghidra_scripts/ — 若干 Ghidra 自动化脚本（Jython），用于导出字符串与函数表等静态信息。
- REPORT_TEMPLATE.md — 分析报告模板，供合作者填充并提交非敏感结果。

使用指引（简要）
1. 在隔离 VM 中启动 Ghidra，新建或打开本地 Ghidra 项目。不要把样本放在联网或共享目录。 
2. 在 Ghidra 中导入本地的 MEMZ.exe（仅在受控环境），按需运行分析选项。 
3. 使用 ghidra_scripts 中的脚本在 Ghidra 环境内导出字符串与函数列表（不会导出可执行文件本身）。
4. 把非敏感的分析产物（例如函数列表、静态分析笔记、截图、hashes.txt）提交到仓库；不要提交可执行文件或脚本完整 payload。

如需自定义或添加脚本/模板，请先在 Issue 中说明用途与安全措施。
